## Adoption decision

Only the LibraStack SDK is the selected match-3 logic candidate. Unity Package Manager consumes its `0.1.3` Unity source package from the full pinned `v0.1.3` commit; the lock records the same commit. Its separate UniTask dependency is also pinned to a reviewed release commit, and both complete MIT notices are retained in [`THIRD_PARTY_NOTICES.md`](THIRD_PARTY_NOTICES.md). No SDK or sample source is copied into project-owned `Assets`. The three reference-only projects and every unidentified or unlicensed source remain absent from executable project trees. The policy validator rejects restricted paths, changed or unpinned SDK references, missing transitive pins, and missing license notices.

Source refs and license file Git blob IDs above are immutable provenance anchors.
