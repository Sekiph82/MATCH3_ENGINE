## Fixed requirements
- Unity installed baseline `6000.6.5f1` (Unity 6.6). LibraStack Match3-SDK (MIT) is the primary upstream. Pin commit and licenses; Unity 2021 sample compatibility with Unity 6.6 remains unverified.
- Do not copy unlicensed `daltonbr/Match3` source code or graphics into a commercial engine. Its Level01–03 concepts are references only pending rights review.
- Exactly one package for Coral_Rescue, Garage_Legends, Dino_Islands, The_Fractured_Realms, Wonder_Pop. Theme-independent game rules, identical world/chapter/level, stars/rewards/tasks/economy/save schema.
- All reusable logic, combo effects and content delivery must be implemented and independently audited **before** any branded game implementation.
- Level Factory is a separate repo that imports engine rules and versioned schema; never silently duplicates its solver.
- Over-the-air updates may include verified levels, data and permitted assets only. New executable C# needs store build. No write tokens/secrets in app.

## Global acceptance conditions
- Deterministic engine core: same config/seed/actions → same board, goals, scores and event trace. Every mutation tested for invalid targets, no moves, interruptions and rollback.
- Compile clean on Unity 6.6; relevant EditMode + PlayMode regression; mobile lifecycle, performance and memory profiled. No untested PASSED milestones.
